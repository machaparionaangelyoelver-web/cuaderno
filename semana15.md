<h2>🧠 Resumen ejecutivo</h2>

En esta semana se trabajó el enfoque de <b>Sistemas Inteligentes</b> aplicado en Python, combinando dos estrategias de decisión:

<ul>
  <li><b>Reglas IF THEN</b>: lógica determinística basada en condiciones claras (si ocurre A, entonces se concluye B).</li>
  <li><b>Lógica difusa</b>: razonamiento gradual para variables con incertidumbre (bajo, medio, alto) y decisiones que no son “todo o nada”.</li>
</ul>

La práctica se orientó a construir un flujo completo: <b>captura de entradas</b>, <b>evaluación (inferencia)</b>, <b>resultado</b> y una <b>explicación breve</b> que permita comprender por qué el sistema llega a una conclusión.

<h2>📚 Marco conceptual</h2>

<details>
  <summary><b>¿Qué es un sistema inteligente?</b></summary>
  <br/>
  Un sistema inteligente es un conjunto de componentes que permiten <b>percibir</b> información del entorno, <b>razonar</b> con base en conocimiento o modelos, y <b>actuar</b> generando una salida útil para el usuario. En esta semana se enfatiza que un sistema inteligente no solo produce un resultado, también debe ofrecer una <b>explicación</b> que permita justificar la decisión.
</details>

<details>
  <summary><b>Reglas IF THEN</b></summary>
  <br/>
  Un modelo por reglas representa conocimiento mediante condiciones. Cada regla tiene:
  <ul>
    <li><b>Antecedente</b>: condición o conjunto de condiciones.</li>
    <li><b>Consecuente</b>: conclusión o acción.</li>
  </ul>
  Ventajas: claridad, facilidad de mantenimiento, explicabilidad directa (se indica la regla activada).
</details>

<details>
  <summary><b>Lógica difusa</b></summary>
  <br/>
  La lógica difusa permite representar conceptos graduales. En lugar de afirmar que un valor es “alto” o “no alto”, se usa un grado de pertenencia μ(x) entre 0 y 1. Un sistema difuso trabaja con:
  <ul>
    <li><b>Variables lingüísticas</b> (bajo, medio, alto).</li>
    <li><b>Funciones de pertenencia</b> (triangular, trapezoidal, etc.).</li>
    <li><b>Reglas difusas</b> (IF temperatura es alta THEN riesgo es alto).</li>
    <li><b>Defuzzificación</b> para obtener un valor final.</li>
  </ul>
</details>

<h2>🧪 Prácticas desarrolladas</h2>

<h3>1) Reglas IF THEN (decisión determinística)</h3>

<table>
  <tr>
    <td width="50%"><b>Propósito</b></td>
    <td>Convertir criterios del dominio en reglas claras para tomar decisiones consistentes.</td>
  </tr>
  <tr>
    <td><b>Estrategia</b></td>
    <td>Evaluar condiciones en orden, aplicar prioridades y devolver una conclusión con explicación.</td>
  </tr>
  <tr>
    <td><b>Salida esperada</b></td>
    <td>Resultado + regla activada (o motivo principal).</td>
  </tr>
</table>

<b>Pseudocódigo</b>
```text
si entrada inválida -> retornar error y solicitud de corrección
para cada regla en orden:
  si condición se cumple:
    retornar conclusión + explicación (regla activada)
retornar conclusión por defecto + explicación
```

<h3>2) Lógica difusa (decisión gradual)</h3>

<table>
  <tr>
    <td width="50%"><b>Propósito</b></td>
    <td>Manejar incertidumbre y gradualidad cuando la decisión no es binaria.</td>
  </tr>
  <tr>
    <td><b>Elementos</b></td>
    <td>Variables lingüísticas, pertenencias, reglas difusas, agregación y defuzzificación.</td>
  </tr>
  <tr>
    <td><b>Salida esperada</b></td>
    <td>Valor final + interpretación (etiqueta dominante) + explicación breve.</td>
  </tr>
</table>

<b>Esquema de inferencia</b>
```text
fuzzificación: calcular μ para cada etiqueta
aplicar reglas: combinar pertenencias para activar salidas
agregación: unir salidas parciales
defuzzificación: obtener valor final
explicación: etiquetas con mayor influencia
```
